# ProofPost Roadmap

## V1: Operational Alpha [CURRENT]
*   Stable local-first runtime.
*   Deterministic fact extraction and verification.
*   Authoritative human-in-the-loop approval flow.
*   Basic platform adapters (LinkedIn, Bluesky).
*   SQLite WAL persistence and crash recovery.

## V1.1: UX Stabilization
*   Review Workspace enhancement (Previews, source context).
*   Setting validation (Connection tests).
*   Enhanced observability (Traceability log).

## V1.2: Review Workspace Improvements
*   Batch approval.
*   Platform-specific content overrides.
*   Draft management.

## V2: Advanced Orchestration
*   Multi-platform orchestration.
*   MCP (Model Context Protocol) integration.
*   Advanced traceability graph.
*   Team collaboration features.
